# 星云数码演示店：转人工政策

- policy_id: DEMO-ESCALATION-001
- version: 1.0
- effective_from: 2026-10-01
- scope: 星云数码演示店
- status: demo（虚拟店铺，仅供开发测试）

转人工情形：质量故障、超期申请、定制商品争议、损坏或缺配件、异常签收时间、政策冲突、未收货纠纷。
整理订单号、申请类型、用户原因、商品状态、政策编号和规则判断结果，创建 pending_review 工单。不得承诺已退款或审核通过。
信息不足时先追问，不伪造订单号或故障证据。订单不存在时请用户核对，不创建无订单工单。
用户仅咨询资格时只回答判断，不自动创建工单；明确提出“申请”“帮我创建工单”才创建。
