# 星云数码演示店：退款流程

- policy_id: DEMO-REFUND-001
- version: 1.0
- effective_from: 2026-10-01
- scope: 星云数码演示店售后工单
- status: demo（虚拟店铺，仅供开发测试）

流程：提交申请 → 资格检查或人工审核 → 寄回指引 → 商品寄回 → 验收 → 核定退款 → 原支付渠道处理。
pending_return 表示等待寄回，pending_review 表示等待人工审核。两种状态均不表示退款完成。
演示服务承诺：人工目标在两个工作日内首次处理；验收通过后目标在三个工作日内发起退款，到账时间取决于支付渠道。这些仅为虚拟服务承诺。
当前系统只创建和查询模拟工单，refund_executed 始终为 false，不连接支付系统，不实际执行退款，也不推进验收或审核状态。
