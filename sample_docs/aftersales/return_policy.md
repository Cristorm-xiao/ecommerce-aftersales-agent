# 星云数码演示店：无理由退货政策

- policy_id: DEMO-RETURN-001
- version: 1.0
- effective_from: 2026-10-01
- scope: 中国大陆地区星云数码演示店普通非定制键盘、鼠标、充电器
- status: demo（虚拟店铺，仅供开发测试）

## 适用条件
普通商品在实际签收次日起计算七天内可申请无理由退货，演示程序按中国大陆本地日期计算：截止日期为签收日期加七天，当日仍可申请。以物流实际签收日期为准，不以点击确认收货时间为准。
商品应保持功能、外观完好、配件齐全。为检查商品进行合理拆包不直接判定为损坏；不把“已拆封”自动等同于不可退货。

## 所需信息与流程
查询订单签收时间与商品类别，询问功能、外观及配件情况。符合条件可以创建 pending_return 工单，寄回后仍须验收。资格通过不代表退款已执行。

## 例外与人工审核
定制商品需要核实适用例外及购买时确认情况。超期、损坏、缺配件或日期异常转人工，不直接拒绝所有售后。未签收订单先查询物流，再人工处理取消或未收货问题。
