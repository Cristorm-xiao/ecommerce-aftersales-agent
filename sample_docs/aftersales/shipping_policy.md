# 星云数码演示店：运费政策

- policy_id: DEMO-SHIPPING-001
- version: 1.0
- effective_from: 2026-10-01
- scope: 中国大陆地区星云数码演示店
- status: demo（虚拟店铺，仅供开发测试）

个人原因无理由退货，演示店未提供运费险或免费退货权益，寄回运费由买家承担。
质量问题、错发漏发、运输损坏，先登记人工审核；确认属于店铺责任后由店铺按核定标准承担合理寄回运费。审核前运费为 pending_review，不承诺具体补偿金额。
用户应等待客服给出寄回地址与指引；本演示不生成真实地址、真实快递单或取件预约。
