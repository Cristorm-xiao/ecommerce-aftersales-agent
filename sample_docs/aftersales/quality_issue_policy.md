# 星云数码演示店：质量问题处理

- policy_id: DEMO-QUALITY-001
- version: 1.0
- effective_from: 2026-10-01
- scope: 星云数码演示店商品
- status: demo（虚拟店铺，仅供开发测试）

无法开机、无法充电、按键失灵等故障登记为质量问题申请。收集订单号、故障描述、购买凭证和已有排查记录，可建议用户提供图片或视频供人工核实。
所有质量问题先进入 pending_review，人工或品牌售后核实故障及适用保修条款后决定退货、换货或维修。模型和图片描述不能代替检测结论。
七天无理由期限与质量问题售后不同，超过七天不能直接推断无任何售后权利。演示店不自行虚构全品类统一保修期限。
质量责任和运费承担需审核确认；创建工单不代表审核通过或退款完成。
