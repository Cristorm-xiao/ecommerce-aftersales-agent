星河知识助手常见问题
资料性质：本文件为虚构的 RAG 测试素材，不代表实际系统配置。
文档版本：2026-10-08

问题一：为什么上传文件后回答找不到内容？
请先检查文件状态是否为“索引完成”。“上传成功”只表示原始文件已收到，不表示内容已经写入向量数据库。
如果文件已经索引完成，请确认查询选择了正确的知识库。扫描版 PDF 还需要检查是否已经执行 OCR。

问题二：如何提高文档检索效果？
建议按主题整理文档，并保留标题、文件名和页码。相同主题的段落尽量放在一起，避免把无关内容混入同一片段。
文档入库与查询必须使用相同的 embedding 模型和输出维度。更换模型后，需要重新生成文档向量，不能直接混用旧模型向量。

问题三：聊天记录和知识库文档有什么区别？
聊天记录用于同一个会话的上下文延续，按会话 ID 隔离。
知识库文档用于按语义检索资料，只有经过文档入库流程的内容才会进入知识库。聊天消息不会自动成为知识库文档。

问题四：知识库能回答今天的新闻吗？
只有已经入库的资料才能被检索。知识库不会自动更新当天新闻。
如果需要实时信息，应调用网络搜索工具，并检查搜索结果的发布日期和事件发生日期。

问题五：如何联系客服？
测试客服邮箱为 support@xinghe.example，工作时间为周一至周五 09:00 至 18:00，时区为北京时间，不含节假日。
提交上传问题时，请提供文件名、文件格式、文件大小、处理状态和错误提示。不要在邮件中提交 API 密钥。

问题六：取消订阅是否会立即删除数据？
取消自动续费不会立即删除数据，当前已付费周期内仍可使用。
退款通过后的数据导出和删除安排，请以《星河知识助手退款政策》中的“退款后的数据”条款为准。
