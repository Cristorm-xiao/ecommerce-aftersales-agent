# RAG 测试素材

本目录包含三个虚构产品文档，用于验证文档切分、向量入库、检索和回答。TXT 文件采用 UTF-8 编码。这些文件尚未上传至 Pinecone。

入库时请选择三个 `.txt` 文件，并保留来源文件名；本 README 不必入库，避免预期答案干扰检索测试。

| 测试问题 | 预期要点 | 来源 |
|---|---|---|
| 专业版多少钱，每月可以问多少次？ | 每月 99 元，5000 次问答 | 01_产品说明.txt |
| 上传的 PDF 有哪些限制？ | 单文件最大 20 MB，最多 300 页；扫描版需先 OCR | 01_产品说明.txt |
| 首次买专业版第 5 天，已经问了 450 次，可以全额退款吗？ | 可以，仍在 7 日内，450 次不超过 500 次门槛 | 01_产品说明.txt、02_退款政策.txt |
| 首次买专业版第 5 天，已经问了 501 次，可以全额退款吗？ | 不符合全额退款条件，超过 500 次门槛 | 02_退款政策.txt |
| 自动续费 24 小时后，已经问了 1 次，可以全额退款吗？ | 不符合，续费规则要求新周期问答次数为 0 | 02_退款政策.txt |
| 退款审核和到账分别需要多久？ | 完整材料收到后 2 个工作日审核；退款发起后 3 至 5 个工作日到账 | 02_退款政策.txt |
| 上传成功为什么还搜不到？ | 上传成功不等于索引完成；检查知识库选择和 OCR | 03_常见问题.txt |
| 取消自动续费会立即退款并停止使用吗？ | 不会自动退款，当前周期权益仍可使用 | 02_退款政策.txt、03_常见问题.txt |
| 星河知识助手的年度订阅价格是多少？ | 文档没有提供，应明确资料不足 | 无 |

测试时不只检查是否返回片段，也要检查答案是否忠于片段、能否区分首次订阅和续费规则，以及缺少依据时是否承认未知。
